# Lumen10 Guardian

Execute `Guardian: Abrir painel` na paleta de comandos. O backend inicia em segundo plano.
O painel usa os dados reais do plano de controle em loopback e mantém a credencial na memória do host da extensão.

`Guardian: Abrir PowerShell` abre um terminal nativo. O comando de contexto de um incidente abre um documento ao lado do Codex, sem automação de teclado nem envio silencioso ao chat.

Configure `guardian.home` somente se a pasta `lumen10_guardian_ia` estiver fora do workspace.
Requer workspace confiável, Python/venv instalado e PowerShell 7 no Windows.
